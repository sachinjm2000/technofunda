How this is scored — rules, sizing, caveats How to read this. Every name ever published on the Filtered Watchlist (Composite ≥ 96 · industry group rank ≤ 60), scored from its entry-day close under a 8% stop and a +20% target. Those levels come from the exit grid: a 1:1 payoff was the worst cell tested at +0.66R, while +20% against the same stop gives +0.92R. Status uses intraday highs and lows — a stop is a resting order, so it fills on a touch, not on a close. When one bar touches both levels the stop is assumed, since a daily bar does not record which came first.
One entry per stock, on its first appearance. The watchlist relists a name every night it stays qualified, so scoring every listing would count the same trade several times and let a name that already ran re-enter at each higher price.
The summary is unit-weighted, not a plain average: an RS ≥ 90 name counts twice. Rupee figures use ₹30,000 for an RS ≥ 90 name and ₹15,000 otherwise — change with --unit. Booked is cash from positions that hit their stop or target; Open is mark-to-market and can still move. ⚠️ Basis is a short, single-regime sample — this page exists to accumulate evidence, not because the rule is validated.
